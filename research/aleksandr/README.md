# Исследования Александра — только ноутбуки

Рабочая ветка: `feature/aleksandr-signals-ml`.
В командный репозиторий передаём ноутбуки с кодом, пояснениями и сохранёнными
результатами. Отдельные Python-скрипты, тесты, отчёты и выгрузки сюда пока не входят.
Прежняя полная версия исследования сохранена локально вне командного репозитория.

## Файлы

| Ноутбук | Содержание |
|---|---|
| [fx_signals_kaggle.ipynb](notebooks/fx_signals_kaggle.ipynb) | Исходная работа: данные, EDA, индикаторы, target, модели и walk-forward |
| [fx_signals_kaggle_hybrid.ipynb](notebooks/fx_signals_kaggle_hybrid.ipynb) | Исходная работа и эксперимент с гибридным слоем, разделы 17–24 |
| [fx_signals_kaggle_candidates.ipynb](notebooks/fx_signals_kaggle_candidates.ipynb) | Последняя версия: предыдущие разделы и экономический фильтр, разделы 25–31 |

**Начинай с последней версии.** В ней уже есть предыдущие разделы; два других
файла оставлены для сравнения этапов. Функции встроены в ячейки — локальные
`fxsignals`, `hybrid_layer.py`, `candidate_layer.py` и запускатели не нужны.
Содержание и сохранённые результаты ноутбуков при очистке не менялись.

## Запуск

Основной вариант — импорт `.ipynb` в Kaggle:

1. Прикрепить `rates.csv` как Dataset / Add Input.
2. Выбрать CPU, без ускорителя.
3. Нажать Run All.

Если файла нет, предусмотрена загрузка официальных курсов ЦБ РФ через интернет.
Интернет также понадобится, если в среде отсутствует пакет `holidays`.
Данные не включаются в Git. Для локального запуска `rates.csv` можно положить
рядом с ноутбуком либо в `research/aleksandr/data/`; эти файлы игнорируются Git.
Локальная среда Jupyter и библиотеки настраиваются отдельно, общие зависимости
команды ради исследовательского ноутбука не меняются.

Сохранённые графики и таблицы доступны без повторного обучения. Полный Run All
пересчитывает эксперименты и может занять около 10–15 минут, в зависимости от среды.
Большие промежуточные журналы, которые появятся после запуска, в Git не входят.

средняя частота 0,790–0,913 отправки в неделю. Требования lift ≥ 1,3 и частоты

Это отдельное исследование, не готовая интеграция с командным загрузчиком.
Старый формат `rates.csv` использует `available_date` и `rub_per_unit`;
у командного загрузчика другие поля и допущение о дате доступности.
Подключение к нему согласуем и проверим отдельно.

## Правила совместной работы

- Редактируем свою копию в `research/aleksandr/notebooks/`, не чужие файлы.
- Один и тот же ноутбук одновременно редактирует один участник.
- `.gitignore` разрешает добавлять из этой папки только её README, сам
  `.gitignore` и `.ipynb` непосредственно из `notebooks/`.
- Перед коммитом проверяем код и вывод ячеек: в разрешённом файле тоже могут
  случайно оказаться токены, пароли или лишние данные.
- Отправляем свою ветку в форк и открываем Pull Request в оригинал команды;
  в `main` напрямую не пишем.

Из корня репозитория подготовить этот набор можно так:

```bash
git add research/aleksandr
git diff --cached --name-status
```

Ожидается пять файлов: README, `.gitignore` и три ноутбука. Очистка сама по себе
не создавала коммит и не отправляла файлы на GitHub.
