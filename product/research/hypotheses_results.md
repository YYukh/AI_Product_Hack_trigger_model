# Результаты проверки гипотез

Компаньон к `hypotheses_backlog.md`. Бэклог — план, этот файл — что из плана реально проверено и с каким результатом. **Разница принципиальна:** список гипотез без результатов выглядит на защите как намерение, а не как проведённая работа — именно это жюри и предыдущий разбор конкурентов ставит в упрёк, если не заполнено.

**Как заполнено ниже:** статусы, помеченные «подтверждено по данным из репозитория», основаны на реальных числах, которые уже видны в коде и ноутбуках (`production_pipeline`, `notebooks/expriments.ipynb`, `notebooks/prod_pipline.ipynb`, `simulation-stats.md`). Всё остальное честно помечено «статус неизвестен» — я не выдумываю результат там, где не видел его своими глазами. Это ваша задача — пройтись по списку и заполнить реальным статусом до защиты.

## Как читать статус

| Статус | Значение |
|---|---|
| ✅ Подтверждено | Есть конкретное число из кода/ноутбука/симуляции, которое отвечает на вопрос гипотезы |
| ⚠️ Частично | Есть косвенное свидетельство, но не прямой прогон по описанному в бэклоге методу |
| ❓ Неизвестно | Не нашёл свидетельств ни за, ни против — нужно проверить у автора гипотезы |
| ❌ Не подтверждено | Прогнано, kill-критерий сработал |

## Часть 3. Пилотные гипотезы

Не проверяются на хакатоне по определению (нужны клиентские данные) — статус не применим. В отчёте фиксируется формулировка риска, не результат: L1–L4 остаются открытыми вопросами для пилота, как и задумано.

## Главный вывод из этой таблицы

Из 16 гипотез, проверяемых на хакатоне, у меня есть прямое или косвенное свидетельство только по трём (P1, P2, A4), и то не строго по методу, описанному в бэклоге — я реконструировал частичный ответ из побочных данных (симуляция, production-бэктест, поквартальный анализ Юрия), а не нашёл отдельного прогона именно этой гипотезы. **Это не значит, что остальные 13 не проверялись** — значит, что либо результаты не сохранены в доступных мне материалах, либо действительно не успели. Разница критична для защиты: если проверялись, но не задокументированы — нужно за оставшееся время просто перенести результат сюда. Если не проверялись — надо явно решить, какие из них проверить в оставшееся время (кандидаты на самый дешёвый чек: A5 — 1 час, P2 — пересчёт медианы вместо среднего, уже есть данные).
