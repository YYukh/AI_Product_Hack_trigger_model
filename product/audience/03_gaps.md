# Чего в источниках нет

Произносить на защите самим, до вопроса жюри. Не выдавать эти величины за оценки. Номера в скобках после [Ф] ссылаются на `04_sources.md`.

| № | Пробел | Статус |
|---|---|---|
| 1 | **День месяца и привязка к зарплатному циклу** | Ни МВД, ни ЦБ РФ, ни банки такой разбивки не публикуют. Единственный твёрдый внутримесячный якорь — обязательный ежемесячный платёж по патенту |
| 2 | **Средний чек в разрезе гражданства отправителя из России** | ЦБ РФ **Ф[3.6]** публикует объёмы по странам, но не чеки; банковские чеки смешаны с переводами россиян |
| 3 | **Доля пользующихся картой против наличных среди мигрантов** | Прямого замера нет; косвенно — устойчивое предпочтение офлайн-получения при онлайн-отправке |
| 4 | **Поведенческие данные по армянскому коридору** | Есть макроцифры ЦБ Армении **Ф[3.5]**, нет ни одного публичного исследования отправителей-мигрантов |
| 5 | **Дезагрегированные по полу данные по Узбекистану** | В обзоре РАНХиГС **Ф[2.2]** прямо указано, что отсутствуют |
| 6 | **Точная годовая доля России в переводах в Узбекистан** | ЦБ Узбекистана **Ф[3.1]** не раскрывает; публикуются только квартальные доли (72,4% в I кв. 2026) и оценка «около 80%» |
| 7 | **Объёмы неформального сектора** | По определению вне официального учёта; оценка 20–40% — экспертная, источник не назван (см. `04_sources.md`, «Пункты без точного источника»), количественно не верифицируема |
| 8 | **Диаспора vs. активные отправители (Армения)** — *добавлено по итогам ресёрча регионов, сентябрь 2026* | Открытые данные о расселении армян в России (перепись, 950 тыс. человек **Ф[1.5, 6.3]**, концентрация в Краснодарском и Ставропольском краях **Ф[2.5]**) описывают **всю этническую диаспору**, включая давно осевших российских граждан без активных денежных связей с Арменией. Отдельной статистики по **действующим трудовым мигрантам**, отправляющим переводы, — только косвенные цифры въезда (154,5 тыс. в 2025 **Ф[1.4]**). Смешение этих двух популяций — вероятная причина, почему вес портрета 4 (5%) не сходится с макроцифрами ЦБ Армении при сверке агрегатов (см. `docs/simulation/04_sensitivity.md`) |
| 9 | **Региональная специализация по странам исхода** — *добавлено по итогам ресёрча регионов* | Есть только один датированный источник **[В, 2.6]** (не позднее 2020–2021), предполагающий, что Приволжье привлекательно для узбекских мигрантов, а Дальний Восток — для киргизских. Актуальность на 2025–2026 не проверена, в модель не закладывается без дополнительного подтверждения |
